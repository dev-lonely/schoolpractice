HOW TO OPEN
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in your browser, or use Live Server if you have it installed.
4. Use the navigation links to visit the other pages.

JUNIOR-DEVELOPER NOTES
- This is a plain HTML and CSS front-end. There is no JavaScript, Bootstrap, framework, font import, or external image dependency.
- The stylesheet is local and linked with a normal relative stylesheet path.
- The contact form is visual only. To receive and save enquiries, connect it to a backend and database.
- Greenfield Academy and the address/contact details are sample content. Replace them with the real school's information.
- The hero and activity panels use CSS gradients rather than downloaded photos, so the website works offline.

If by "no importing link" you mean no external URLs, this project uses no external resources. The local CSS file still needs a <link rel="stylesheet"> tag to style all pages from one stylesheet. If you want absolutely no <link> tags at all, CSS must be placed inside <style> tags in each HTML page.
